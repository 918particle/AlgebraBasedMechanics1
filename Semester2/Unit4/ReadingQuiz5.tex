\section{Memory Bank}

\begin{itemize}
\item $\epsilon = -L \frac{\Delta I}{\Delta t}$ ... Faraday's law with induction, $L$.  Think of this as the change in voltage across an inductor.
\item $X_{\rm C} = 1/(2\pi f C)$ ... The reactance of a capacitor with capacitance $C$, at frequency $f$.
\item $X_{\rm L} = 2\pi f L$ ... The reactance of an inductor with inductance $L$, at frequency $f$.
\item $Z_{\rm tot} = \sqrt{R^2 + (X_{\rm L} - X_{\rm C})^2}$ ... The total impedance of an RLC series circuit.
\item $\tau = RC$ ... The time constant of an RC circuit.
\item $f_0 = \frac{1}{2\pi\sqrt{LC}}$ ... RLC circuit resonance frequency.
\item $i(t) = \frac{\epsilon}{R}\left(1 - \exp(-t/\tau) \right)$ ... Current in a charging RL circuit.
\item $i(t) = \frac{\epsilon}{R}\exp(-t/\tau)$ ... Current in a discharging RL circuit.
\item $\tau = L/R$ ... Time constant of an RL circuit.
\item $V_{\rm rms} = I_{\rm rms} Z_{\rm tot}$ ... Ohm's Law for AC circuits.
\end{itemize}
